<p align="center">YouTube-style keyboard shortcuts for Spotify: playback, seeking and volume.</p>

## Keybinds

| Key | Action |
| --- | --- |
| `Left` / `Right` | Seek -5s / +5s (hold to repeat) |
| `Up` / `Down` | Volume +5% / -5% (hold to repeat) |
| `J` / `L` | Seek -10s / +10s (hold to repeat) |
| `K` | Play / pause |
| `M` | Mute / unmute |
| `0` to `9` | Jump to 0% - 90% |
| `Home` / `End` | Jump to start / end |
| `Shift + N` / `Shift + P` | Next / previous track |

Ignored while typing. `Ctrl` / `Alt` / `Cmd` chords are left untouched.

## Installation

**Marketplace:** search for **YouTube Keybinds** in the Extensions tab and install.

**Manual:** copy [`youtubekeybinds.js`](youtubekeybinds.js) into your Spicetify
Extensions folder ([docs](https://spicetify.app/docs/advanced-usage/extensions)), then:

```bash
spicetify config extensions youtubekeybinds.js
spicetify apply
```
